# Robot Jumping Game

A simple 2D web-based jumping game created using HTML, CSS, and JavaScript.

## Features
- Interactive Start Screen
- Keyboard Controls
- Simulated Gravity and Jump Mechanics
- Randomized Obstacles
- Precise Collision Detection
- Dynamic Scoring System

## Technologies Used
- HTML5
- CSS3 (Keyframe animations and positioning)
- JavaScript (Game loop, DOM manipulation, collision logic)

## How to Play
1. Open the game in your web browser.
2. Click the START GAME button.
3. Press the Spacebar to jump over the incoming obstacles.
4. Survive as long as possible to get the highest score. Hitting an obstacle ends the game.

## Setup Instructions
To run this game locally:
1. Clone this repository or download the files.
2. Ensure all image assets are in the same directory as the code files.
3. Open the index.html file in any modern web browser.
